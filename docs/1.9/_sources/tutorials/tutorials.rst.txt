.. _tutorials:

#########
Tutorials
#########

This section contains tutorials that teach you how to use Maia by practising with selected examples.

To run the tutorials, a valid installation of maia is requested. If you are within
ONERA network, you can use the version deployed on Juno (see :ref:`environnements <quick_start>`).
Otherwise, you have to build your own version (see :ref:`installation`).

Almost all tutorials are splitted in two parts.
The first part aims to be interactive and invite you to:

- answer questions indicated by the symbol ❓,
- write code to complete a step when you see the symbol ✏️.

You are strongly encouraged to have a go yourself before looking at the solution.

The second part usually provides more detail or introduces more advanced
concepts.
This structure enables you to experiment safely first and then deepen your understanding.

The following tutorials are available:

+------------------------+---------------------------------------------------------+-------------+
| Tutorial               | Synopsis                                                | Difficulty  |
+========================+=========================================================+=============+

+------------------------+---------------------------------------------------------+-------------+

+------------------------+---------------------------------------------------------+-------------+
| :ref:`tuto4`           | Start to manually manipulate partitioned meshes         |  ★★★☆☆      |
+------------------------+---------------------------------------------------------+-------------+

Although each tutorial can be completed independently, it is recommended that you start with the easiest ones.
