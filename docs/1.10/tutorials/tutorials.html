Tutorials

This section contains tutorials that teach you how to use Maia by practising with selected examples.

To run the tutorials, a valid installation of maia is requested. If you are within ONERA network, you can use the version deployed on Juno (see environnements). Otherwise, you have to build your own version (see Installation).

Almost all tutorials are splitted in two parts. The first part aims to be interactive and invite you to:

  • answer questions indicated by the symbol ❓,

  • write code to complete a step when you see the symbol ✏️.

You are strongly encouraged to have a go yourself before looking at the solution.

The second part usually provides more detail or introduces more advanced concepts. This structure enables you to experiment safely first and then deepen your understanding.
